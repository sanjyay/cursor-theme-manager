# Cursor Theme Manager Repository Instructions

Before investigating, editing, testing, or reviewing this repository, read and
follow the repository-root `AGENTS.md`.

When working in a directory that contains its own `AGENTS.md`, read and follow
that file in addition to the repository-root instructions.

In particular:

- Changes under `scripts/` must follow `scripts/AGENTS.md`.
- Changes under `tests/` must follow `tests/AGENTS.md`.

These files define mandatory project security, filesystem-safety, restoration,
testing, and Git requirements.

Do not weaken existing security controls or introduce unsafe fallbacks merely
to make an operation succeed.
